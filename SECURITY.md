# Security policy

Please do not put vulnerability details in a public issue, pull request or discussion.

Use GitHub's private vulnerability reporting if the repository's **Security** tab
offers **Report a vulnerability**. If it does not, open an issue that only asks for a
private contact channel, without any details of the problem.

Only the latest release receives fixes.

Last.fm credentials are stored unencrypted in Home Assistant's config entry and in its
backups, as the README describes; that is known behavior. If you shared a log or
backup that may hold credentials, revoke the access in your Last.fm settings.
